# Agents

This project uses an agent knowledge base. ALWAYS read `agent/agent.md` first and
follow its routing table — read only the sub-file(s) relevant to your task.

After making changes, keep `agent/state.md` and `agent/decisions.md` updated, and
refresh `agent/graph/` when the structure changes. Never store real secrets in the
agent folder.

Global guidance and model-routing rules live in `~/Documents/brain` (`leader.md`).
